## 📄 Deskripsi Proyek
Proyek ini adalah tugas UTS praktikum untuk:
- Mendeteksi warna (merah, hijau, biru) menggunakan HSV
- Meningkatkan citra low-light menggunakan brightness dan CLAHE
- Analisis histogram distribusi warna

## 🧪 Fitur Utama
- Segmentasi warna berdasarkan HSV
- Konversi citra ke grayscale
- Perbaikan pencahayaan dengan penyesuaian brightness & kontras
- Analisis histogram RGB
- Perbaikan citra backlight (tubuh jadi pusat perhatian)

## 🚀 Cara Menjalankan
1. Buka file `.ipynb` menggunakan Jupyter Notebook
2. Jalankan sel dari atas ke bawah
3. Pastikan gambar input berada di direktori yang sama
